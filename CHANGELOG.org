Notable changes to the intended public interface are recorded here: the root
flake's =lib= output and functionality supplied through its functions.
Compatibility is not currently promised, even for that interface. Other accessible
contents are internal and carry no compatibility guarantee. See
[[file:README.org][README]] for usage, detailed behavior and internal maintenance.
Development entries describe implemented changes; their scope remains open until
explicitly frozen.

** Added
*** =lib.mkFlake=
**** Flake construction
Construct flakes with flake-parts, shared module arguments and configurable
per-system Nixpkgs overlays, with explicit argument validation and diagnostics.

**** Treefmt integration
- Provide a shared treefmt formatter and default formatting check, covering
  Nix, shell, Prettier-supported files, Haskell, Cabal, XML, Python and TOML.
  Unmatched files are errors; consumers configure explicit exclusions.
- Make =pkgs.treefmt-wrapper= available through =mkFlake='s per-system package
  set for formatting during package builds. It shares the formatter defaults
  and is configured independently of =perSystem.treefmt=.
- Extend treefmt with =gitignore-fmt= for root and nested =gitignore=,
  =.gitignore= and =*.gitignore= files, following the project's whitelist
  convention. Operational failures are reported explicitly, and original files
  are preserved on failure.
- Extend treefmt with Lisp formatters: =lisplens= for Scheme and
  =elisp-autofmt= for Emacs Lisp.
- Extend treefmt with =bibtex-tidy= for root and nested UTF-8 =.bib= files,
  using two-space indentation, aligned fields and blank lines between entries.
- Extend treefmt with Org-mode formatting through Emacs's native Org AST
  parse/interpret round-trip. Normalize blank lines around headlines and their
  leading planning and drawer elements, and uppercase all node-property names
  without changing property values, order or duplicates. Other normalization
  is delegated to Org's native serializer, without formatting embedded
  programming languages or adding special-block adapters.
- Extend treefmt with =text-fmt= for root and nested =.txt= files.
  Normalize CRLF to LF and append a final LF to nonempty unterminated files,
  preserving other bytes including whitespace and blank lines. Reject NUL
  and inputs whose normalization would not be idempotent.

**** Development environment
Provide a =nix= development shell using patched Nix to address false circular
imports and incorrect locked-source reuse with nested relative inputs.
The patched Nix uses a pinned upstream release flake with its own locked build
dependencies, independently of the caller's Nixpkgs.

*** =lib.mergeAttrsRecursive=
- Merge attribute sets recursively with conflict diagnostics and optional
  later-entry override precedence.

*** =lib.packages=
- =mkOverlays= provides directory-based overlays, nested scopes, Emacs and TeX Live
  integration, and independent groups with =include=, =exclude=, external
  =overlays= and directory-constrained package exports.
- =mkNixosModule= and =mkHomeModule= provide recursive module discovery.

*** =lib.tests=
- =mkChecks= assembles an independent test scope and uses the shared overlay
  tree selector for directory-selected derivations.
- Accept nested explicit check trees and select final values at the originally
  declared paths. Initial declarations must be valid test trees and declared
  node types must be preserved by overlays. Do not automatically export
  overlay-added members of explicitly registered namespaces.
- Require a non-derivation attribute set at the root of =checks=, and report
  invalid selected values with their attribute paths and types.
- Accept =recurseForDerivations = true= metadata in explicit test trees without
  using it to control selection.
- Combine structured check trees before flattening with configurable names.
  Distinct attribute paths producing the same flattened name now fail instead
  of silently overwriting a check.
